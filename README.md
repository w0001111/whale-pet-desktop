# Whale Pet · 大肥鱼桌宠

一只可以离线住在 Mac 桌面上的蓝色大肥鱼。拖一拖、挥个手，让它在二维桌面范围内散步；需要聊天时，再连接你自己的 AI。

<img src="assets/pet.png" width="180" alt="蓝色大肥鱼角色素材">

Whale Pet 是独立开源项目，与 OpenAI、DeepSeek 及其他模型服务商没有官方隶属关系。使用发行包不需要安装 DeepSeek Harness、Node、npm 或其他开发环境。

## 下载与安装

需要 **macOS 15 或更新版本**。请从本仓库右侧的 **Releases**，或[最新发行版页面](../../releases/latest)选择与你的 Mac 匹配的包。若页面尚未提供资产，请等待该版本发布，或按下面的源码构建说明操作。

| Mac 类型 | 架构 | v0.1.0 文件名 |
| --- | --- | --- |
| Apple 芯片，M 系列 | `arm64` | `Whale-Pet-0.1.0-macos-arm64.dmg` 或 `.zip` |
| Intel 芯片 | `x86_64` | `Whale-Pet-0.1.0-macos-x86_64.dmg` 或 `.zip` |

打开 DMG，或先解压 ZIP，将 **Whale Pet.app** 拖入 **Applications（应用程序）**，然后打开。两个架构的发行包分别内置 Node **24.22.2** 和官方 Codex CLI **0.164.0**；普通使用者无需另装运行时。

当前版本尚未使用 Developer ID 签名和 Apple 公证，首次打开可能被 macOS 阻止。确认下载来源与版本后，按[安装指南](docs/INSTALL.zh-CN.md)通过“系统设置 → 隐私与安全性 → 仍要打开”允许这个应用。无需关闭系统安全功能。

## 能做什么

| 功能 | 需要 AI 吗 | 说明 |
| --- | --- | --- |
| 桌面宠物 | 不需要 | 透明悬浮、拖动、尺寸调整、挥手与表情气泡。 |
| 二维散步 | 不需要 | 在可见桌面范围内移动、转向、停留，拖动或交互时暂停。 |
| 8 个动作片段 | 不需要 | 起身、站立、走路、吃东西、坐下、欢呼、游戏、听音乐。游戏和音乐是角色动画。 |
| 本地提醒与待办 | 不需要 | 在“提醒与待办”中管理，通过运行中的桌宠显示。 |
| 用量与预算 | 查看与设置不需要 | 查看服务返回的用量，为后续主动 AI 设置本地预算。 |
| 本地记忆 | 管理不需要 | 显式保存你提供的资料，在记忆窗口查看、删除。AI 聊天可使用已保存记忆。 |
| 聊天与陪伴 | 可选 | 连接自己的 Codex 账号或兼容 API；主动 AI 默认关闭。 |
| 只读网页任务 | 需要已配置 AI | 读取公开网页、整理来源，不登录、不发帖、不修改文件。 |

提醒依赖应用和本机服务运行，不是系统级闹钟；应用退出、电脑睡眠或关机时不保证按时触发。网页任务也不等同于控制浏览器或电脑，不能读取登录后的私人页面。

## 第一次打开

首次向导提供三个选择，之后都可从菜单栏的鲸鱼图标或宠物右键菜单进入“AI 连接设置”。

1. **离线桌宠**：先玩宠物、动作和本地小工具，随时可以再接 AI。
2. **Codex 账号**：使用应用附带的官方 CLI，在官方页面完成独立登录。本应用不会导入其他 Codex 应用已有的账号目录。
3. **API 兼容服务**：选择 Responses 或 Chat Completions，填写 Base URL、模型和自己的 API Key，先保存，再按需点击“测试连接”。同一服务可留空保留 Key；更换不同服务时须重新填写。

保存设置、刷新本地状态和登录流程不会发起模型生成。“测试连接”会发送一次小模型请求；普通聊天、网页结果整理和你开启的 AI 主动消息也会消耗所选服务的额度。

Codex 接入属于 **隔离只读受限模式（实验）**，首版仅支持文字聊天，不上传截图。应用限制 CLI 的工具能力，并在发现工具尝试时中断该次生成；这些限制不等于完整的操作系统隔离，也不应被理解为“绝对无工具”。API 模式可使用你选择的视觉模型处理显式附带的截图。详见[连接配置](docs/CONFIGURATION.md)和[安全说明](SECURITY.md)。

API 的模型权限、价格和费用由你选择的服务决定。Codex 的可用模型、登录权限和额度以你的官方账号及 ChatGPT 计划为准，不承诺所有计划可用，也不承诺无限额度。[官方身份验证说明](https://learn.chatgpt.com/docs/auth)可用于核对当前账号要求。

## 默认隐私选择

- **应用信息默认关闭**：不会默认把前台应用名称、窗口标题附到聊天中。你可以独立勾选“聊天时附带应用信息”。本地目标预览不表示信息已发送。
- **截图默认关闭**：仅在你显式开启、授予系统录屏权限并发送聊天时，按频率限制准备一张窗口图像；不会定时截屏。成功附图时可同时附带截图目标信息。
- **主动 AI 默认关闭**：需要你自行开启。开启后的 AI 生成会消耗额度，不会主动截图。
- **不复制旧账号与用户数据**：发行包不包含维护者账号、聊天、记忆、截图或其他使用者的数据。

默认用户目录为 `~/Library/Application Support/WhalePet`，其中 `data/` 保存设置、聊天、记忆、提醒、任务记录、用量及服务配置。Codex 的独立登录目录也在这个用户根目录下。应用资源与用户数据分开，正常替换 `.app` 不会把用户数据一起覆盖。可用 `WHALE_PET_DATA_DIR` 指定其他目录，包括外盘；详见[配置文档](docs/CONFIGURATION.md#数据目录与更新)。

API Key 使用本机权限受限的文件保存，不在设置读取接口或输入框中回显；这不是磁盘加密或系统钥匙串。不要公开用户数据目录。完整说明见[隐私文档](PRIVACY.md)。

## 从源码构建

构建 `.app`、DMG 和 ZIP 需要 macOS 15+、Xcode Command Line Tools 与 Python 3。在项目根目录运行：

```sh
xcode-select --install
python3 scripts/package-macos.py --arch arm64
```

Intel 包使用：

```sh
python3 scripts/package-macos.py --arch x86_64
```

首次构建需要联网准备运行时；`package-macos.py` 在缺少缓存时调用 `fetch-runtime.py`，按 `runtime-lock.json` 下载并校验锁定的官方版本，已有缓存也会核对文件校验值。构建和发行包不需要安装 Harness，也不需要执行 `npm install`。

后端源码测试需要 Node 24+ 和 npm；测试没有外部 npm 依赖：

```sh
npm test
```

测试使用合成数据与模拟服务；真实账号登录、真实模型生成和目标机器上的系统权限仍需要单独验证。开发环境覆盖变量与无 GUI 诊断命令见[配置文档](docs/CONFIGURATION.md#开发与诊断)。

## 使用限制与帮助

目前不提供私人社交平台自动浏览、发帖或桌面控制。动态网页、登录墙、反爬限制和网络故障都可能使只读网页任务失败；搜索摘要不等于已经读取目标正文。AI 回复也可能不准确，请结合实际来源和界面显示的截图发送状态判断。

每日 token 预算只暂停后续主动 AI；显式聊天、测试连接和手动网页任务仍可产生调用。它不是服务商账单的严格封顶，一次响应可能越过阈值，服务商未返回完整用量时统计也可能不完整。
