# 日常姿态素材 v1

这些透明背景的二维动画素材由 AI 生成，参考项目内的 `../pet.png` 和 `../pet-sprites.png`，保留蓝色卷发、鲸鱼帽、女仆装、鲸鱼尾巴和 Q 版画风。

生成提示集合（工作提示的目标与约束记录）：

- Movement：生成透明 3×3 精灵图。第一行依次坐着、蹲起、完全站立，第二、三行共六帧向右走路的循环。腿与手臂应交替，头部与服饰保持一致，尾巴在身后。各帧全身完整、不相互接触，无文字、分格线、背景或阴影块。
- Eating：生成透明 2×2 精灵图。相同角色坐着端鲸鱼图案的小碗，依次舀饭、举勺至嘴、闭眼鼓腮咀嚼、放下勺子；全身与鞋子完整，角色身份、碗、服饰和尺度一致，无文字和背景。
- 第二轮布局修正：保持上述身份与动作，将人物缩小并置于各格中央，留足透明外边距，避免鞋子和尾巴被格边切断，要求相同头部与地面注册位置。实际输出仍有不等留白，使用manifest中固定正方形atlas矩形描述完整帧，不修改生成PNG像素。

取帧位置见 [manifest.json](manifest.json)，只引用选用的 v2 图像。图像保留生成时的像素；运行时由 CoreGraphics 按 atlas 裁帧、缓存、统一显示比例并对齐脚底。角色的基础生成提示可参见 [asset-prompt.txt](../asset-prompt.txt) 和 [sprites-prompt.txt](../sprites-prompt.txt)。

动作包只在启动或手动重新加载时读盘；播放、翻转和位移完全本地，不调用模型。角色在不同姿态间采用离散绘制帧，不是骨骼或3D动画。
