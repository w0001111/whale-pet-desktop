# 安装与首次启动

Whale Pet 的发行包适用于 macOS 15 或更新版本。可以先离线使用桌宠，不必先注册账号或配置 AI。

## 1. 选择正确的架构

在苹果菜单中打开“关于本机”：

- 显示“芯片：Apple M…”：选择 `arm64`。
- 显示“处理器：Intel…”：选择 `x86_64`。

从本仓库右侧的 **Releases** 进入对应发行版。v0.1.0 的文件命名如下；实际提供的资产和校验信息以该发行版页面为准。

| 架构 | DMG | ZIP |
| --- | --- | --- |
| `arm64` | `Whale-Pet-0.1.0-macos-arm64.dmg` | `Whale-Pet-0.1.0-macos-arm64.zip` |
| `x86_64` | `Whale-Pet-0.1.0-macos-x86_64.dmg` | `Whale-Pet-0.1.0-macos-x86_64.zip` |

发行包已内置对应架构的 Node 24.22.2 与官方 Codex CLI 0.164.0。普通安装无需另装 Harness、Node、npm 或 Python。

## 2. 拖入应用程序

使用 DMG 时，双击挂载，打开后将 **Whale Pet.app** 拖入 **Applications（应用程序）**。使用 ZIP 时，先解压，再将得到的 **Whale Pet.app** 拖入应用程序。

从“应用程序”打开已复制的应用。不要长期直接运行 DMG 中的副本；复制完成后可以推出安装磁盘映像。

## 3. 处理首次打开提示

当前发行包尚未使用 Developer ID 签名与 Apple 公证，因此 macOS 可能提示无法验证开发者或阻止首次打开。仅当你确认文件来自本仓库的 Releases、选择了正确版本，并核对了发行页提供的校验信息后，再允许这个应用。

1. 先从“应用程序”尝试打开 **Whale Pet.app**，关闭拦截提示。
2. 打开 **系统设置 → 隐私与安全性**。
3. 找到刚刚被阻止的 Whale Pet 项目，点击 **仍要打开（Open Anyway）**。
4. 按系统要求完成确认和账号验证，再打开应用。

该选项通常需要先发生一次拦截才出现，且可用时间有限。具体界面与判断方式请参照 [Apple：安全地打开 Mac 上的 App](https://support.apple.com/en-gb/102445)。macOS Sequoia 对未正确签名或公证软件的首次打开流程有所调整，[Apple 的说明](https://developer.apple.com/news/?id=saqachfa)要求通过系统设置完成相应允许。

这一步是对特定应用的允许。不要全局关闭 Gatekeeper，也不要通过删除隔离属性来替代正常的系统流程。如果系统提示文件受损、包内容异常或检测到恶意软件，请先停止打开并重新核对下载与发行说明。

## 4. 完成首次向导

第一次启动会出现“AI 连接设置”。

- **先离线使用**：大肥鱼可拖动、挥手、播放动作和散步，本地提醒与待办也不需要模型账号。
- **Codex 账号**：点击官方登录按钮，在打开的官方页面完成你自己的账号授权。应用使用自己的独立配置目录，不读取其他 Codex 应用的登录文件。
- **API 兼容服务**：选择协议，填入服务商提供的 Base URL、模型名称和自己的 Key，保存后再按需测试。同一服务可留空保留已保存 Key；更换不同服务地址时须重新填写。

保存和刷新设置不会发起模型生成；**测试连接会使用一次小模型请求**。详细步骤、Codex 实验限制及费用说明见[配置文档](CONFIGURATION.md)。

以后可从菜单栏的鲸鱼图标、宠物右键菜单或聊天窗口中的“AI 连接设置”重新进入。

## 5. 保留默认的隐私选择，或按需开启

新用户的应用信息、截图和主动 AI 均默认关闭。

“聊天时附带应用信息”是独立开关，开启后才会在发送聊天时附上可取得的应用名和窗口标题。“本地目标预览”只用于本机提示，不代表信息已经发送。

截图需要你在聊天窗口显式开启，并在 macOS 的 **隐私与安全性 → 屏幕与系统音频录制** 中按系统流程授权。界面名称可能随系统版本略有不同。首版 Codex 模式只支持文字，不上传截图；截图识别需要 API 模式和支持视觉输入的模型。

普通拖动、动作和本地提醒不需要录屏或辅助功能权限。不要为了这些离线功能额外开放系统权限。

## 更新、退出与卸载

更新前先从鲸鱼菜单选择“退出大肥鱼”，再用新版本替换“应用程序”中的旧 `.app`。用户数据位于 `~/Library/Application Support/WhalePet`，与应用资源分开；正常替换应用包不会自动清除这些数据。

在更换版本或应用身份后，macOS 可能要求重新确认录屏权限。使用稳定的安装路径，先完整退出再重启；需要重新授权时按系统流程处理，参见[排障文档](TROUBLESHOOTING.md#截图开关已开启但仍未发送截图)。

卸载时先退出应用，再移除 `.app`。这不会自动删除本地聊天、记忆、账号与其他状态。若还希望清除用户数据，请先确认备份需求，再手动处理自己使用的 WhalePet 数据目录。不要删除其他应用的账号目录，也不要把用户数据目录上传到公开 issue。
