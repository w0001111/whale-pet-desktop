# AI 连接与本地配置

从菜单栏鲸鱼图标、宠物右键菜单，或聊天窗口进入“AI 连接设置”。不配置 AI 也可以使用桌宠动画、拖动、二维散步和本地小工具。

## 三种连接方式

| 方式 | 身份与费用 | 首版能力 |
| --- | --- | --- |
| 离线桌宠 | 无模型账号、无模型请求 | 动作、散步、气泡、本地提醒与待办，以及本地数据管理。 |
| Codex 账号 | 在官方页面独立登录；权限与额度由你的账号决定 | 隔离只读受限模式（实验），仅文字；不上传截图。 |
| API 兼容服务 | 自备服务地址、模型权限与 Key，按该服务的规则计费 | 文字；视觉模型可处理显式附带的截图。 |

这些选择不要求安装 DeepSeek Harness。发行包已附带支持版本的官方 Codex CLI。Codex 的账号条件与当前支持的身份验证方式以[官方身份验证文档](https://learn.chatgpt.com/docs/auth)为准；不能据此推断任意 ChatGPT 计划都支持，或拥有无限用量。

## 离线使用

选择“离线桌宠”并保存，或在首次向导点击“先离线使用”。这不会创建模型连接。

离线时可以使用菜单中的动作、散步、尺寸调整、“提醒与待办”和本地数据管理。提醒由运行中的本机服务处理，通过桌宠显示；退出、关机或系统睡眠时不保证按时触发。

## Codex 账号

1. 选择“Codex 账号”。通常不需要填写 CLI 路径，发行包会使用附带的官方 CLI。
2. 点击“在官方页面登录 Codex”。
3. 在打开的官方网页中选择你自己的账号并完成授权。
4. 返回设置窗口等待状态更新。必要时点击“刷新状态”。
5. 按需点击“测试连接”。测试会发起一次小模型请求。

模型框可以留空，由官方 CLI 使用账号可用的默认选择；也可显式填写你的账号支持的模型。切换提供方时应重新核对模型，不要沿用另一家 API 的模型名。

应用把自己的账号配置放在独立目录中。它不会导入其他 Codex 应用的登录状态；“退出本应用的 Codex 账号”只针对这一份独立连接。

Codex 接入标签是 **隔离只读受限模式（实验）**。应用采用独立配置与工作目录、只读策略和拒绝升级授权，限制命令、本地图像及其他集成工具；发现工具尝试或未知操作时会中断该次生成。兼容检查未通过时不会启用模型生成。这些限制不等于完整操作系统隔离，不应描述成“绝对无工具”。详情见[安全说明](../SECURITY.md)。

首公开版 Codex 只支持文字，不上传窗口截图。想让模型识别截图，请改用 API 模式和支持视觉输入的模型。底层协议的开发资料可参考官方 [App Server](https://learn.chatgpt.com/docs/app-server) 与 [Codex SDK](https://learn.chatgpt.com/docs/codex-sdk) 文档；普通安装不需要另装 SDK。

## API 兼容服务

1. 选择“API 兼容服务”。
2. 根据服务商文档选择 **Responses** 或 **Chat Completions**。
3. 填写 **Base URL**，例如 OpenAI 官方服务使用 `https://api.openai.com/v1`。第三方服务应使用其自己公布的地址。
4. 填写该服务支持、且你有权限访问的 **模型名称**。
5. 在安全输入框中填入自己的 **API Key**，点击“保存连接设置”。
6. 保存后再按需点击“测试连接”。

Base URL 应填写服务根路径，通常不包含最后的 `/responses` 或 `/chat/completions`。地址中不要放账号、Key、查询参数或片段。远程服务需要 HTTPS；HTTP 仅适用于后端允许的本机回环地址。

保存配置只表示设置写入本机，并不证明 Key、模型权限、余额或网络有效。“测试连接”使用**已保存的连接**发送一次小模型请求；修改输入后请先保存。测试成功也不保证视觉输入可用，视觉能力还取决于所选模型与服务。

当前 Responses 请求使用 `max_output_tokens`，Chat Completions 请求使用 `max_tokens`，要求所选服务和模型支持这些参数；不自动转换为厂商的其他专有字段。连接测试的输出额度较小，某些推理模型可能用完额度仍没有可见文字。遇到这类情况，先核对协议和模型兼容性，优先选择该服务支持的 Responses 接口或适合简短聊天的模型；测试失败本身不能证明 Key 一定无效。

Key 保存后不会填回输入框。占位文字“同一服务留空保留；换服务须重填 Key”表示只会为同一服务保留已有值。更改 Base URL 的协议、主机或端口会清除旧 Key，必须重新填写；同一服务仅改路径可保留。要移除 Key，请使用“删除已保存的 API Key”。本地配置文件有受限的文件权限，但不是加密存储或系统钥匙串，请妥善保护整个用户数据目录。

## 应用信息、截图与主动 AI

三个开关相互独立，新用户默认均为关闭。

| 选择 | 开启后会发生什么 |
| --- | --- |
| 聊天时附带应用信息 | 仅在你发送聊天时，附上可取得的应用名称、窗口标题。标题可能包含文档名或联系人信息。 |
| 聊天附图 | 显式授权录屏后，在支持视觉的 API 聊天中按额度附一张前台窗口图像；成功附图可同时附截图目标信息。 |
| 主动聊天 | 由本机规则安排后续陪伴消息；选择 AI 生成时会消耗所选服务额度。不会主动截图。 |

两个桌面上下文开关都关闭时，聊天不附应用名、窗口标题或图像。“本地目标预览”仍可在本机显示目标，但不会因此发送它。单独打开截图、且本轮没有取得截图时，不会把应用信息作为隐含回退发送。

截图不会定时采集，只在显式发送聊天时准备。默认发送限制为**至少间隔 10 分钟、每日最多 12 张**；可在“截图设置”调整。间隔填 `0` 表示每条聊天都可以附图，每日张数填 `0` 表示不设本地每日张数上限。关闭截图开关仍可停止附图。增加张数可能增加费用，频率限制不会判断内容是否敏感。

主动聊天需在其设置中自行开启。可以暂停、设置勿扰、使用专注时段和互动退让。经济模式会结合本地短句与少量 AI；AI 模式的每次生成都会消耗额度。首版部分日期与日预算按 `Asia/Shanghai` 计算，跨时区使用时请核对界面显示的日期与时段。

## 用量与预算

“用量与预算”显示服务实际返回的模型用量、截图及主动消息记录。`tokens` 是模型用量单位，不能直接当作金额；不同服务、模型和缓存计费规则可能不同。

每日 token 预算达到阈值后，只暂停后续主动 AI；显式聊天、测试连接和手动网页任务仍可产生调用。填 `0` 表示不设置这个主动 AI 的本地日 token 阈值，不代表服务商提供无限额度。一次模型响应可能超过阈值；未知或不完整的用量也会影响统计。设置预算后，无法确认用量时可能暂停后续主动 AI。

手动只读网页任务另有单次时长、模型次数和工具次数限制。当前界面上限为 3 分钟、8 次模型调用和 12 次工具；达到该任务的单次 token 阈值后停止其后续模型调用，单次响应仍可能越过阈值。这些单次限制不表示每日主动 AI 预算会拦截新的手动任务。轮询任务列表和本地状态本身不调用模型。

## 本地记忆

可以在聊天中用明确的“记住：……”保存你提供的资料，例如“记住：我喜欢简洁的回答”。在“长期记忆”窗口查看、删除相应内容。管理本地记录不调用模型；后续 AI 回复可把相关记忆发送给已连接的服务。

“新对话”、历史聊天和长期记忆是不同的数据。开始新对话不会自动删除已保存记忆，也不代表之前发送给服务商的请求已被撤回。

## 数据目录与更新

默认用户根目录：

```text
~/Library/Application Support/WhalePet
```

其下 `data/` 保存偏好、聊天、记忆、提醒、用量、服务令牌与提供方配置等。Codex 的独立配置、工作目录及临时目录也位于这个用户根目录下。不要将该目录上传到公开仓库、issue 或共享下载包。

应用资源位于 `.app` 内的 `Contents/Resources/service`，运行时位于 `Contents/Resources/runtime`。正常更新应先退出应用，再替换 `.app`；不需要把用户数据复制进新应用包。

`WHALE_PET_DATA_DIR` 可以把**整个用户根目录**放在其他位置，包括已挂载的外盘。它不是 `data/` 子目录本身，也不会自动迁移旧数据。示例中的路径是占位路径，须替换成你自己的可读写绝对目录：

```sh
WHALE_PET_DATA_DIR="/absolute/path/to/WhalePet" \
  "/Applications/Whale Pet.app/Contents/MacOS/WhalePet"
```

迁移前退出应用并备份，再复制整个原用户根目录，保留原副本以便核对。不要让两个实例同时写入同一个目录；外盘使用前应确认已经挂载且可读写。这个环境变量必须在每次启动时提供；之后直接从 Finder 双击，未必继承刚才终端里的环境设置。

## 开发与诊断

发行包无需设置这些变量。开发时可使用：

| 变量 | 用途 |
| --- | --- |
| `WHALE_PET_DATA_DIR` | 独立用户根目录，避免开发和日常实例共用状态。 |
| `WHALE_PET_RESOURCE_DIR` | `.mjs` 与 `assets/` 所在的资源根目录。 |
| `NODE_BINARY` | 开发用 Node 可执行文件的完整路径。 |
| `WHALE_PET_CODEX_BINARY` | 开发用官方 Codex CLI 的完整路径。 |
| `WHALE_PET_PORT` | 本机服务端口，默认 `43928`；开发实例需要各自独立的数据目录和端口。 |

当前实现使用 `WHALE_PET_CODEX_BINARY`，不读取裸 `CODEX_BINARY` 变量。原生合成探针的 `WHALE_NATIVE_TEST_ROOT` 只用于测试编译，不是普通用户的迁移设置。

以下命令不打开 GUI，不启动模型或截图；诊断只报告路径、版本和资源状态，不输出 Key、服务令牌或账号身份：

```sh
"/Applications/Whale Pet.app/Contents/MacOS/WhalePet" --version
"/Applications/Whale Pet.app/Contents/MacOS/WhalePet" --diagnostics
```

诊断中的资源不存在或可执行文件不可用，通常表示应用包不完整，或开发环境覆盖变量指向了不匹配的位置。不要直接修改发行 `.app` 内的脚本和二进制来修复连接设置；这可能改变签名身份并影响系统权限。
