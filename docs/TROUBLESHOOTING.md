# 常见问题与排障

先确认应用版本、macOS 版本和处理器架构。菜单中的设置可以重开；无需通过反复重装或删除用户目录来处理普通连接问题。

## macOS 阻止首次打开

当前发行包尚未使用 Developer ID 签名和 Apple 公证。先确认文件来自本仓库 Releases、架构正确，并核对发行页提供的校验信息。

从“应用程序”尝试打开后，进入 **系统设置 → 隐私与安全性 → 仍要打开**，按系统提示允许这个应用。选项可能要在发生拦截后才出现。[Apple 的操作说明](https://support.apple.com/en-gb/102445)和 [Sequoia 行为变更说明](https://developer.apple.com/news/?id=saqachfa)解释了这一流程。

不要全局关闭 Gatekeeper，也不要把删除隔离属性当作安装步骤。若提示文件受损或检测到恶意软件，请停止打开，重新核对下载和版本说明。

## 双击后看不到宠物

1. 查看菜单栏是否出现鲸鱼图标，用“找回宠物”把它移回当前屏幕。
2. 确认已把 `.app` 复制到“应用程序”，而不是直接运行 DMG 内副本。
3. 核对包架构：M 系列使用 `arm64`，Intel 使用 `x86_64`，系统需要 macOS 15+。
4. 若刚更新，完整退出旧实例后再打开新副本。

应用作为桌面伴侣运行，不必始终显示 Dock 图标。若仍无法启动，可以执行文末的无 GUI 诊断，检查包内资源和运行时是否齐全。

## 宠物不散步，或“游戏/音乐”没有控制其他应用

先在鲸鱼菜单开启“开始散步”。交互、拖动、聊天窗口打开、悬停或某些状态会暂停移动；系统的“减少动态效果”设置也会影响动画与运动。它在二维桌面范围内散步，不会跨进其他应用执行操作。

“游戏”和“听音乐”是角色动作片段，不会自动打开游戏、播放音频或控制播放器。

## 提醒没有准时出现

确认提醒仍处于待处理状态，应用和本机服务没有退出，电脑没有关机或睡眠。提醒在运行中的桌宠气泡或对话里显示，不是系统级闹钟，也不保证系统休眠期间准点触发。

首版部分日期与日预算使用 `Asia/Shanghai`；跨时区使用时请核对界面时区、提醒时间和勿扰时段。

## 聊天提示未连接或服务未就绪

离线桌宠仍可使用。进入“AI 连接设置”，确认选中的方式、保存结果和连接状态。

- 刚启动时，本机服务可能需要片刻准备。稍后点一次“刷新状态”。
- API 模式先保存，再点击“测试连接”；仅保存成功不能证明网络、Key 和模型权限有效。
- Codex 模式需要本应用自己的独立登录。其他 Codex 软件已经登录，不代表本应用也已授权。
- 若正在生成聊天或执行任务，连接修改可能暂时被拒绝；先停止或等待当前操作结束。

本机服务默认只监听回环端口 `43928`，并使用本应用数据目录中的令牌认证。不要把端口暴露到公网，也不要从别的应用目录复制令牌。

## Codex 登录没有完成，或授权后仍不能聊天

在“AI 连接设置”中选择 Codex，点击官方登录按钮，在打开的官方网页里完成自己的账号授权，再回到窗口等待状态更新。需要退出时，用“取消登录”或“退出本应用的 Codex 账号”。

检查模型框是否误填了另一家 API 的模型名。Codex 模型可留空使用官方 CLI 默认；可用性、计划要求及额度以[官方账号身份验证说明](https://learn.chatgpt.com/docs/auth)和实际服务响应为准。

若显示“尚未通过受限模式兼容检查”，即使账号已授权也不会启用生成。优先使用当前发行包附带的官方 CLI，不要随意替换成未验证的版本。可以继续离线使用，或改用 API。

Codex 是隔离只读受限模式（实验）：工具尝试或未知操作会使本次生成中断。被中断不代表任务已经完成。此模式不承诺“绝对无工具”，能力边界见[安全说明](../SECURITY.md)。

## API 测试失败

依次核对：

1. 协议是否与服务一致：Responses 或 Chat Completions。
2. Base URL 是否为服务根地址，通常不应额外拼上 `/responses` 或 `/chat/completions`。
3. 远程地址是否使用 HTTPS，且没有把 Key 放进 URL。
4. 模型名称是否正确，账号是否有该模型的访问权限、余额或可用额度。
5. 输入修改后是否先保存。测试使用已保存连接。

Key 输入框在保存后为空是正常行为；“同一服务留空保留；换服务须重填 Key”不表示密钥丢失。更改服务地址的协议、主机或端口时，旧 Key 会被清除，需重新填写；这用于防止旧 Key 被发送到另一个服务。同一服务仅改路径可以保留。要更换 Key，可填新值并保存；要删除，使用专门的删除按钮。

测试会消耗一次小模型请求。不要为了排查而连续重复测试；先根据错误状态检查配置和服务商网络。测试文字成功也不能证明当前模型支持图像。

## 截图开关已开启但仍未发送截图

先看聊天里的“本轮”发送状态，不要仅凭开关位置判断。依次确认：

1. 当前是 **API 模式**，且模型支持视觉输入。Codex 首公开版仅文字，不上传截图。
2. 聊天截图开关已显式打开；应用信息是另一项独立选择，不等于截图授权。
3. macOS 的 **系统设置 → 隐私与安全性 → 屏幕与系统音频录制** 已允许对应的 Whale Pet。
4. 发送时有可用的目标窗口；默认 10 分钟间隔和每日 12 张限制尚未用完。
5. 如刚授权、更新应用或系统要求重启，先完整退出 Whale Pet，再重新打开。

权限绑定应用身份，不能仅靠一个开关或反复刷新恢复。保持稳定的安装路径与相同的签名身份；更新后若系统要求重新授权，按正常流程完成。当前版本未使用 Developer ID，替换或重新构建应用可能影响 macOS 对身份的识别。不要全局关闭系统安全功能来处理录屏权限。

测试时可先切到不含私人内容的文档，在其中写一个自己的测试标记，再发消息询问标记。频率限制只控制发送次数，不判断窗口是否敏感。应用不会定时截屏，也不会因为打开截图设置窗口而发送图像。

## 为什么只发了应用名，或什么上下文都没附

应用信息和截图对新用户默认均关闭。两者都关闭时，聊天不附桌面上下文；“本地目标预览”仍然可以显示本机目标。

只有显式开启应用信息时，才会在发送聊天时附上可取得的应用名和窗口标题。系统未提供标题时可能只有应用名。单独开截图但没有取得图像时，不会隐含回退发送应用信息；成功截图可附目标元数据。

## 网页任务失败、只搜到摘要或未读到帖子

后台任务只读取公开网页，不登录、不发帖、不控制浏览器。登录墙、JavaScript 动态加载、反爬或网络故障都可能阻止正文读取。搜索结果只证明搜索页已读取，不代表目标帖子或页面正文已经读到。

查看任务里的来源与工具记录。停止、失败、达到上限和完成是不同状态；未取得结果时不要把连接错误当成完成。修改目标或提供可公开访问的具体网址后，再手动启动新任务。

## 用量或预算看起来不一致

界面统计依赖服务返回的用量，可能包含输入、输出和缓存项。不同服务缺失字段时，统计不一定完整；它不是服务商账单。

每日 token 预算达到阈值后，只暂停后续主动 AI；显式聊天、测试连接和手动网页任务仍可产生调用。它不能把已发出的响应截成严格额度封顶，一次响应可能超出阈值。`0` 表示不设主动 AI 的本地日阈值，不代表服务商无限量。若主动 AI 因未知用量暂停，请先检查提供方返回与预算状态。

## 数据目录换到外盘后“丢了记录”

`WHALE_PET_DATA_DIR` 选择的是整个用户根目录，不会自动搬迁旧数据。确认指定了正确的绝对目录、外盘已挂载并可读写，而且每次启动都使用同一环境设置。Finder 双击不一定继承终端中临时设置的变量。

先退出应用，保留原目录与新目录的备份，再核对是否复制了完整用户根目录；不要只拷贝 `data/` 后遗漏独立 Codex 账号目录，也不要同时运行两个实例写同一目录。详见[数据目录说明](CONFIGURATION.md#数据目录与更新)。

## 无 GUI 诊断与问题反馈

从终端执行：

```sh
"/Applications/Whale Pet.app/Contents/MacOS/WhalePet" --version
"/Applications/Whale Pet.app/Contents/MacOS/WhalePet" --diagnostics
```

这些命令只检查版本、路径和资源状态，不打开 GUI，不启动模型或截图，也不输出 Key、服务令牌或账号身份。诊断中的本机路径仍可能暴露目录名称，分享前请脱敏。

普通 issue 可提供应用版本、macOS 版本、架构、复现步骤和脱敏错误代码。不要上传完整用户目录、原始账号文件、Key、聊天、屏幕图像或未检查的日志。安全问题请按[安全报告说明](../SECURITY.md)提交。
