# Windows 安装与首次启动

首个 Windows 版本为 **0.2.0-windows.1 测试版**，目标是更新后的 **Windows 11 x64**。当前没有原生 ARM64 或 32 位包，也未把 Windows 10 列为已验收平台。

## 下载安装

从本仓库 Releases 选择 Windows 测试版，下载以下任意一种：

| 文件 | 使用方式 |
| --- | --- |
| `Whale-Pet-0.2.0-windows.1-windows-x64-setup.exe` | 安装向导，默认仅为当前用户安装，可创建快捷方式和卸载入口。 |
| `Whale-Pet-0.2.0-windows.1-windows-x64-portable.zip` | 完整解压，进入 `Whale Pet` 文件夹，双击 `WhalePet.exe`。不要只取出其中一个 EXE。 |

两个包都包含所需 .NET、Node 和官方 Codex CLI，不需要另外安装 Harness、Node、.NET SDK、WSL 或开发环境。安装目录可以自选；放在外盘时应先确认磁盘已挂载。

这是未使用 Authenticode 证书签名的测试版。Windows 可能显示“未知发布者”或 SmartScreen 提示。先核对仓库、版本和发布页 SHA-256 清单；只在确认是你要运行的本项目后，按系统界面提供的选项操作。无需关闭 Defender、防火墙或全局系统防护；企业策略禁止运行时，应按组织要求处理。

## 首次运行

大肥鱼出现后，右键角色或系统托盘鲸鱼图标打开菜单。首次设置可选择：

1. **离线桌宠**：使用动作、二维散步、气泡、本地提醒与待办。
2. **Codex 账号**：点击在官方页面登录，完成你自己的账号授权，再回到应用刷新状态。使用独立登录目录，不导入其他 Codex 应用的授权。
3. **API 兼容服务**：选择 Responses 或 Chat Completions，填写 Base URL、模型和自己的 Key，保存后按需测试连接。

保存和登录不会发起模型生成；“测试连接”会发送一次小模型请求。模型访问、额度和费用由自己的账号与服务商决定。Codex 是实验性的隔离只读受限文字模式，不保证完整操作系统隔离。API 协议参数与密钥规则见 [配置说明](CONFIGURATION.md)。

## 功能与首版边界

支持透明桌宠、拖动、二维自动散步、8个动作片段、气泡直接回复、聊天最新定位、本地记忆、提醒与待办、用量与预算、称呼和勿扰/退让、可选主动消息，以及手动启动的只读公开网页任务。

**Windows 首版尚未提供前台应用信息和屏幕截图。** 相关说明会明确禁用，不会读取窗口标题或发送屏幕图像。Mac 上的录屏权限不能用于 Windows；后续适配后需另行说明。主动 AI 默认关闭，需要你自行启用，且不会主动截图。

游戏和听音乐是角色动画，不控制游戏、播放器或系统声音。提醒依赖应用及本机服务运行；退出、睡眠和关机时不保证按时触发。日 token 阈值只暂停主动 AI，显式聊天、连接测试和手动网页任务仍可消耗额度。

## 本地数据与更新

默认用户数据根目录为 `%LOCALAPPDATA%\WhalePet`，其中 `data` 保存设置、聊天、记忆、提醒和提供方配置。Codex 使用该根目录下的独立 profile、工作与临时目录。程序目录与用户数据分开。

API Key 使用当前 Windows 用户及 SYSTEM 可访问的受限文件保存，这不是磁盘加密。不要上传整个用户数据目录、日志或凭据文件。截图、聊天和记忆均不会随安装包分发。

更新前先从托盘菜单**退出**应用，再安装新版本或替换完整便携目录。卸载程序只移除程序文件，用户数据保留。需要删除用户数据时，先退出并自行确认备份。

支持用环境变量 `WHALE_PET_DATA_DIR` 指定整个用户根目录。它不会自动迁移旧数据；不要让多个实例同时写同一目录。示例需替换为自己的目录：

```powershell
$env:WHALE_PET_DATA_DIR = 'D:\WhalePetData'
& 'D:\Apps\Whale Pet\WhalePet.exe'
```

该变量需在每次启动时提供，从快捷方式启动未必继承刚才终端中的设置。

## 诊断与验收范围

在解压目录运行 `WhalePet.exe --diagnostics` 可取得版本、资源是否完整以及默认开关状态；不会启动 GUI、模型、截图或读取账号。不要把包含个人目录的诊断原文直接发到公开 issue。

Windows CI 会检查后端回归、独立临时 HOME 的本机服务、实际到期提醒、空账号 Codex 协议、WPF 合成控件与渲染、安装/卸载和实际包内容。它不等于普通用户电脑上的鼠标、多屏缩放、真实账号模型或屏幕识别验收；以该 Release 的报告为准。
